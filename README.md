Python Learning

Coleção de exercícios e pequenos projetos em Python que desenvolvo para praticar lógica de programação.

Os programas rodam no terminal e usam apenas a biblioteca padrão do Python, sem instalar nada além do próprio Python.

Exercícios
Arquivo	O que faz	Conceitos praticados
calculadora.py	Calculadora com soma, subtração, multiplicação e divisão	funções, while, try/except, if/elif
tabuada.py	Mostra a tabuada de 1 a 10 de um número	for, range, f-strings, validação de entrada
prova.py	Classifica notas em aprovado, recuperação ou reprovado	listas, if/elif/else, for
adivinhe_o_numero.py	Jogo em que o computador sorteia um número de 1 a 1000 e você tenta acertar	random, while, contador de tentativas
megasena.py	Simulador de Mega-Sena: você escolhe 6 números e o programa sorteia	random.sample, listas, validação de entrada

Os prêmios do simulador de Mega-Sena são fictícios; é apenas um exercício de lógica.

Como executar
Instale o Python 3.
Clone o repositório:
   git clone https://github.com/oieusouofp/python-learning
   cd python-learning
Execute o programa que quiser:
   python python/tabuada.py

No Windows, se o comando python não funcionar, use py python/tabuada.py.
